# Hierarquia de Classes — Java

Projeto de estudo desenvolvido em Java para praticar conceitos de Programação Orientada a Objetos.

## Sobre o projeto

O projeto representa uma hierarquia de funcionários, com uma classe base `Funcionario` e tipos de funcionário derivados, como `Assalariado` e `Horista`.

## Tecnologias

- Java
- NetBeans
- Programação Orientada a Objetos

## Conceitos praticados

- Herança e classes abstratas
- Atributos e métodos
- Sobrescrita/implementação de métodos
- Cálculo de salários
- Organização de classes em pacote

## Como executar

1. Abra o projeto no NetBeans.
2. Localize a classe `Principal`.
3. Execute o projeto.

## Objetivo

Praticar a modelagem de classes e os fundamentos de orientação a objetos em Java.
